# Remind Pro - Hệ thống nhắc việc cho Microsoft Teams

Ứng dụng nhắc việc miễn phí thay thế cho Remind (3 USD/user/tháng).

## Tính năng
- Board View phân vai trò (việc được giao / việc đã giao)
- Checklist, ưu tiên P1/P2/P3
- Lặp lại hàng ngày/tuần/tháng
- Gửi Adaptive Card vào Teams qua Webhook
- Scheduler tự động

## Deploy
1. Push lên GitHub
2. Vào [share.streamlit.io](https://share.streamlit.io) → New app
3. Chọn repo này, main file: `app.py`
4. Deploy

## Teams
Xem thư mục `teams_app_manifest` để tạo gói cài đặt.
